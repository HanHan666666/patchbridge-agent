本页演示的架构要点

Agent Runtime 运行在浏览器；默认 Widget 只需一个 JS，本 Demo 额外按需加载 Inspector、Call Trace 与 WebMCP Adapter。

Tool 调用走现有登录态，权限由服务端 RBAC 决定。

远程 MCP Tool 由后端网关代理，凭据不出服务端。首启空库会自动预置麦当劳 MCP 示例（mcd / https://mcp.mcd.cn，未配凭据、默认停用）：在管理后台 → MCP 管理编辑 mcd，认证类型选 bearer、凭据 JSON 填 {"token":"你的令牌"}，保存后启用即可体验真实远程 Tool。

frontend.device_search 直接复用 /demo-api/devices，不经过 /ai/tools/call。

附件、思考、正文和 Tool 交互按 ContentBlock 渲染；刷新页面可验证消息与 ModelState 同 revision 恢复。

样式定制演示

顶栏“主题”可实时切换 8 种风格：深蓝企业、青绿科技、暗色、高对比度、赛博朋克、Win98 复古、奇幻 RPG、NES 像素。

组件侧只通过 --patchbridge-agent-* CSS Variables 与 ::part 覆盖实现，不修改组件任何内部样式，切换即时生效。

赛博朋克 / NES / RPG 的页面特效与素材（扫描线、故障字、霓虹边框、金色浮雕框、像素按钮）来自 vendor/ 下的第三方库，仅在对应主题激活时加载。
